# DialXprt

**DialXprt** is a local service discovery platform designed specifically for the residents of Hyderabad. Find verified Kirana stores, plumbers, electricians, AC technicians, and repair trades near you, with zero commission.

## Features
- **Local Search**: Find verified local service experts near you in Hyderabad.
- **Categorized Services**: Browse easily through categories like Home Services, Travel, Food & Beverage, and more.
- **Progressive Web App (PWA)**: Install DialXprt directly to your device for a fast, app-like experience.
- **Direct Contact**: Contact the provider directly—no forms, no waiting for a callback.
- **Business Registration**: Easy, fast, and free business registration flow.
- **Admin Dashboard**: Manage and verify local business registrations seamlessly.

## Tech Stack
- **Frontend**: React, TypeScript, Vite
- **Styling**: Tailwind CSS
- **Database/Backend**: Supabase
- **Icons**: Lucide React
- **PWA**: `vite-plugin-pwa` for seamless background updates

## Development

First, install the dependencies:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) with your browser to see the result.

## Build
To build the application for production:
```bash
npm run build
```

## Deployment
DialXprt is optimized and configured for easy deployment on platforms like Vercel.
